# Generative AI Foundations for Engineers

### Written by: Clair J. Sullivan
#### Email: clair@clairsullivan.com
### Last modified: 2025-04-17

This is a hands-on course designed to introduce software engineers to how to create basic GenAI applications on AWS with LangChain. The course will cover the following topics:

- Generative AI Foundations and LangChain Basics
- Retrieval-Augmented Generation (RAG) and External Data Integration
- Agents and Tool Use

It is designed such that the learners are provided with a short lecture, then work through a series of activites to learn the material, and finally complete a series of challenges that will be scored as part of a team competition (scoring algorithm not part of this repo).
